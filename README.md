# huxuezha · 个人主页

我的个人主页，纯静态 —— 没有 React，没有构建工具，就是 `index.html` + 一份 `style.css` + 一个 `main.js`。

**在线预览**：<https://huxuezha.github.io/my-first-web/>

## 里面有什么

- **关于** —— 一段自我介绍
- **相册** —— 街拍照片，点击可放大（自己写的灯箱，没用第三方库）
- **项目** —— 我在 GitHub 上的几个仓库

## 目录结构

```
my-first-web/
├── index.html          # 页面结构
├── style.css           # 全部样式（响应式，≤640px 自动切换手机布局）
├── main.js             # 相册灯箱逻辑
├── 红砖麦当劳.jpg        # 相册照片
└── 重庆洪崖洞.jpg        # 相册照片
```

## 本地预览

直接双击 `index.html` 就能看。如果想让地址栏像线上一样干净，可以在项目目录里起一个静态服务：

```bash
python -m http.server 8000
# 然后打开 http://localhost:8000
```
